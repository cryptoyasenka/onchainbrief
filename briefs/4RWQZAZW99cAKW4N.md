# JUPITER PROGRAM ID SWAPS & COMPUTE BUDGETS

![card](4RWQZAZW99cAKW4N.png)

Jupiter provides a Solana-compatible direct interface for swaps, allowing developers to utilize its Program ID for instructional coding. The Solana programming model is elaborated upon in a recent article, which covers essential structures for building applications and includes insights on transaction parsing with a dedicated library. Additionally, the Compute Budget Program specifies a Compute Unit Price of 10 lamports per compute unit, highlighting the cost structure for transactions within this ecosystem.
